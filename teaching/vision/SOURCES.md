# 视觉适配代码与输入来源

`camera.*`复用本项目已验证的MIS5001/`rkisp_demo`采集路径；ISP和内核模块由配套脚本准备。裸NV12管道不携带曝光时间戳，读取结束时刻不能直接用于运动EKF的新鲜度判断。

`detector.cpp`的YOLOv5量化后处理改编自Rockchip RKNN Model Zoo v1.6.0，提交`eaa94d6f57ca553d493bf3bd7399a070452d2774`，Apache-2.0，完整许可随本目录保存。上游：<https://github.com/airockchip/rknn_model_zoo/tree/eaa94d6f57ca553d493bf3bd7399a070452d2774/examples/yolov5>。

本项目适配包括红黑14类、640×640 RGB、固定三头anchors、原生NHWC内存/步长检查、候选数量限制和独立资源回收；这些适配代码计入教学版代码量。模型类别顺序为`kabnrcpKABNRCP`，模型文件及训练/导出证据沿用主项目`tools/model/SOURCES.md`，本轮没有重新训练或更换权重。已验证RKNN模型SHA-256为`c843fac9714d97ca3b478193fb98557fef3146ca4c216a98380295a87c693943`。

`board_vision.*`使用OpenCV 5.0.0 ArUco与单应变换，四角尺寸和像素参考全部从配置传入。稳定盘面须来自多张完整帧，不能对同一定位结果重复调用解释函数凑帧数。棋盘固定标定失配、角标缺失/重复、检测低置信/重复/偏离交点均拒绝推进棋局。

末端观测使用独立标记平面标定，只在已标定Z高度范围内有效。传入时间须是可靠采集时刻，或依据实测采集延迟上界得到的保守时刻；时间来源未校准时保持无效观测。该接口、合成图测试和数学滤波不代表实机视觉闭环已验收。
