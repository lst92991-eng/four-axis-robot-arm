# SCARA中国象棋机器人：项目需求

日期：2026-10-14。教学项目根目录为本目录，分支为`codex/teaching-interfaces`。

## 1. 目标

在RV1106上完成中国象棋人机对局：观察人的走棋、核验合法性、调用Pikafish计算应手、控制SCARA电磁铁搬子/吃子、复拍确认后更新棋局。代码采用C++17，按真实开发顺序逐接口建立，适合逐步讲解和复现。

## 2. 功能需求

| 模块 | 最终需要具备的能力 |
|---|---|
| CAN通信 | 打开指定Linux CAN接口，按CAN ID收发经典帧，有限等待，报告实际通信错误 |
| 电机 | 四轴节点寻址、必要的速度/位置命令、反馈、停止、到位及通信中断处理 |
| 标定与运动 | 回零/零偏、传动单位换算、FK/IK、加减速和多轴协调、实际限位与路径检查 |
| 电磁铁与取放 | 吸取、抬升、搬运、释放、吃子移出；保留中断步骤及可核对的恢复方式 |
| 视觉 | MIPI NV12采集、OpenCV转换/ArUco定位/标定、YOLOv5识别红黑14类并映射90个交点 |
| 运动估计 | 真实编码器反馈；具备独立末端观测时实现运动EKF，明确状态、测量、时间和用途 |
| 棋局与引擎 | 合法走法、历史、结果、Pikafish请求；计划动作与已确认动作分开 |
| 主流程 | 人机轮次、停止、故障提示、复拍确认、重启/中断后核对恢复 |

正式棋盘为9列10行、90个交点。当前规则口径包含普通合法走法、自将检查、将死/困毙、认输及双方约定和棋；重复局面转人工裁定，不冒充已实现完整长将/长捉竞赛裁判。

## 3. 已知输入与待确认项

- 主控RV1106，MIS5001 B MIPI相机，电磁铁末端。
- 现用旧结构CAD轴距195＋275mm；275＋275mm是候选新结构，未确认实装。
- 已购25mm磁性棋子，最终常用棋具目标为33mm；吸附性、棋盘格距及布局需实物确认。
- CAN工具为ZDT_CANable V1.0，Windows已识别candleLight；节点1实物为X42S_V2.0B、Emm闭环、500kbit/s。
- Joint1/M1/节点1为Z：当前接线方向0/A上升，方向1/B下降；Emm位置反馈65536计数/电机圈，转速为整数RPM。
- Z轴上下实测达到过500RPM，已验证F6启动一次、反馈查询、FE停止和低速失联停机。此结果来自既有Windows/Python测试，不等于新教学C++已经接板通过。
- 其他三轴预期可以沿用同类驱动，仍需核对地址/模式/方向；肩轴速比幅值50来自用户确认。
- Z导程、实机零位/行程、各轴标定、工具TCP及棋盘外参仍待确认。不得用仿真假设填成实测值。
- RV1106真实USB Host/CAN/gs_usb链路仍待验证；现有交叉编译与虚拟CAN验证不能代替板端收发。

## 4. 教学实现原则

1. 每次完整展示一个方法，说明调用者、参数、执行顺序、保留/删除理由及失败处理，与用户商定后实现。
2. 参考官方文档和相近开源项目，说明适用差异；不以最少行数替代正确性和可讲解性。
3. 优先直接系统API、普通函数和必要具体对象；不预建抽象基类、工厂、插件、线程队列或完整厂家命令集。
4. 调用参数按已约定教学场景组织；系统/设备的实际失败需有明确结果，不无期限等待或盲重发运动命令。
5. 中文注释说明意图；无限循环采用`while (1)`，有终止条件的循环保留该条件。
6. 新教学代码从空白建立；现有试验代码、模型、日志与机械资料保留在原工作区，作为参考证据，不自动纳入每次提交。

## 5. 提交与审核方式

- 首次提交仅包含本需求文档和[技术栈调研](docs/技术栈调研.md)，没有业务代码。
- 第二次提交开始，每确认并实现一个接口，完成当前范围的验证后独立提交一次；不顺手加入尚未商定的接口。
- 每个提交正文写清：用途与调用场景、接口签名/单位、采用方案及依据、未采用方案及原因、失败与资源处理、验证方法和结果、尚未完成的边界。
- 单接口提交可能尚不能链接成完整应用，需明确当时可完成的编译/验证范围，不添加空实现伪装功能齐全。
- 本地逐接口提交已获用户授权；远端尚未配置，不据此创建远端或自动推送。
- 用户新增的逐接口提交规则优先于此前“整个模块商定后才统一实施/提交”。效果与最终代码审核仍保留；提交不等于冻结或整机验收。

## 6. 完成标准

最终机型与棋具上验证90个交点、实际取放路径、吃子区、完整对局及必要异常恢复。分别记录机械运动、吸放/停稳、视觉和引擎时间，优化走棋耗时。用户确认效果及代码后，固定构建部署、依赖/模型来源和有效参数，按指定版本形成可复现交付。

高频波形日志增强目前暂停。极限速度展示不是每轴接入必须重复的步骤；实际定位与停稳性能仍需验证。
