# 第一步：NV12 转彩色照片

项目棋类已于2026-10-08确定为中国象棋。本步骤是通用的摄像头格式转换；此前15×15棋盘与黑白子分类只属于历史视觉实验，不能代表中国象棋识别已完成。

目标：从本板采集的 `camera.nv12` 中读取第一帧，转成 BGR，再保存 `live/source.jpg`。当前代码只有 `main.cpp`，不需要先摆好棋盘。

核心调用：

```cpp
cv::cvtColor(nv12, bgr, cv::COLOR_YUV2BGR_NV12);
```

- **NV12**：相机当前输出的格式；本实验固定为 1280×960、紧密排列的数据。
- **BGR**：OpenCV常用的彩色像素排列，一个像素包含蓝、绿、红三个数值。
- **JPEG**：保存照片的文件格式，由 `imwrite()` 编码生成。

`nv12` 的 `CV_8UC1` 只表示按单字节存储原始数据，不表示把相机图像变成了灰度图。Y数据占 `宽×高` 字节，UV占一半，所以一帧共 1,843,200 字节，用 `高×3/2` 行装下。

文件部分按 `fopen → fread → fclose` 顺序展开。读取的是第一帧；读不到完整一帧就停止。输入必须来自约定的采集方式，不能把JPEG改扩展名后传入。

在板端执行：

```sh
sh /root/scara-vision-v1/capture.sh
```

脚本准备 `live` 目录并采集文件，程序只负责转换和保存。输出 `Done: live/source.jpg` 后，把照片拉回电脑查看。返回0表示保存成功，1表示文件读写失败；采集脚本超时返回124。

后续按中国象棋9×10布局推进定位与棋子身份识别。此前五子棋视觉实验源码保存在 `output/rv1106/archive/vision-full-before-step1-2026-10-08.zip`，不参与当前构建。
