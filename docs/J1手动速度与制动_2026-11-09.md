# J1 手动速度模式与快速制动

当前固件 `bf3b7ee4`。用户要求手动长按判断实际行程，因此 J1 手动按钮改用 CAN 命令12：参数为有符号毫度/秒，持续加速到指定速度后匀速，松手发送STOP。该模式不使用固定机械角度终点，保留电流、编码器、控制时序、2.5°跟随误差及通信失联保护。位置模式的配置范围不用于手动速度模式。

方向以用户最终更正为准：原始CAN正向下降、负向上升。界面“↑上升”映射到负速度，“↓下降”映射到正速度，显示角度以上升为正。电角编码器方向+1、raw_zero=10088、直连比例1:1保持不变。配置保存在 `config/manual-jog.json`、`config/axis-hardware.json`。

起动加速度仍为10°/s²，STOP使用独立制动减速度360°/s²。固件命令13仅在关闭或停稳保持状态允许临时调整制动参数；最终360已写入构建配置。减速度不改变既有自动定位轨迹的到位规划。

实测结果（包含进入保持状态的停稳确认时间）：

| 速度 | 制动减速度 | 松手后确认停稳 | 故障 |
| --- | --- | --- | --- |
| 90°/s | 120°/s² | 2.415秒 | 0 |
| 90°/s | 360°/s² | 0.800秒 | 0 |
| 180°/s | 360°/s² | 1.110秒 | 0 |

理论速度降为零的时间是速度÷减速度；实际停稳确认还包括闭环跟踪和稳定判定，不能把理论0.25/0.5秒说成实测停稳时间。上位机停止等待根据速度和制动参数计算，已移除原先固定2秒误报超时的问题。
