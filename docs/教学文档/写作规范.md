# 教学文档写作规范

按用户截至 2026-11-12 的反馈维护。

- 排版沿用用户提供的《RV1106小智项目开发教程.docx》，保留真实标题、正文、图文及页面样式。
- 按用户本次明确的范围完成内容。原理课覆盖约四分钟参考视频的原理流程，篇幅随讲解和配图需要展开。
- 内容直接讲清原理和流程，删去空话、重复结论和不服务当前知识点的扩展。
- 电机原理课的开头聚焦电机本身，不主动加入机械臂移动棋子等项目场景。
- 小节标题直接写本节讲的对象或知识点，例如「转子的两段铁芯」「力矩的计算」「H 桥换向」。用来衔接图文的提问放在正文里。
- 分页按图文的实际占用安排。标题与必要引入、图片与图注相连，避免为每个小节强制另起一页造成大块留白；保持正常字号和完整原理。
- 以图为主，文字辅助解释。按当前已讲到的内容选图，不抢先加入动作演示、术语和参数。
- 以读者自然认识事物的顺序组织内容，保证前后承接和层级自然。是什么、有什么作用、为什么、原理是认知过程，不是必须照搬的标题模板。
- 代码用于核对项目事实，不能因为作者掌握完整代码，就按代码需要倒推本节的教学重点。学生尚未建立直观认识的概念不抢先讲。
- 面向从未接触电机的学生。先展示简洁的真实外观照片，说明输出轴和电机能做什么；再展示拆解实拍并介绍定子、转子、线圈；解释磁铁和 N/S 极之后，才进入动作简图。每个新概念先建立直观认识，再使用名称。
- 不能只给原理示意图而跳过实物，也不能把增添图片数量等同于改善讲解顺序。首次讲解先看清一次通电切换带来的动作，再逐步扩展。
- 过渡顺着学生此时自然产生的问题展开。例如讲完“通电产生磁场”，接“磁场为什么能让转子转起来”，后文直接回答磁极作用，再引出方向判断。避免“下面先判断……再看……”这类作者工作安排式过渡。
- 课件正文撤去文末“原理资料”“动作演示”等导航超链接，图片署名与许可采用普通文字，完整来源保留在项目资料记录。
- 原理课在基础模型之后继续讲带齿结构、1.8° 的位置差、两相绕组、四次换相、前后两段转子及共同作用。合编稿在《步进电机的结构和工作原理》讲这些内容。
- 每一步由前一步的结果自然引出：已经能转，再问怎样转得更小；已经能靠挪动磁铁转，再问怎样用电完成。一个图段只改变一个条件，图和文字使用同一模型、视角、颜色和编号。
- 先用四方位磁铁入门，再用固定线圈和带齿结构逐步对应实际电机。图示模型的角度、真实结构的齿距与步距分别通过当前图文建立。固件参数不抢在电机原理之前展开。
- 讲完右手定则后回到前面的同一个模型，放大右侧绕组，用两幅图比较原电流方向与反向电流。箭头沿铜线标 I，沿铁芯内部标 B，两图同步交换 N/S。不要只新增一个与前文失去对应关系的抽象线圈图。
- 原则是先补齐当前动作所需的基础，再呈现模型、解释动作并回到具体部件；“先看动作再讲原因”不能用来跳过必需的磁极知识。
- 正文直接说明事物、作用和过程。删去反复的“不是……”“不能理解为……”“仅适用于本例……”等作者排错或反驳式插话；技术准确性通过选定明确的讲解对象和正面表述保证。
- 在讨论中积累用户对教学顺序与表达的要求，并用于后续内容自审，不让用户逐项重复纠正已经指出的问题。
- 按参考视频的因果流程展开必要概念。合编稿的范围见 `课件编排.md`，单课原稿的范围见 `第一课/内容范围.md`。
- 旧自制 GIF 仍只作历史记录，本轮采用新绘制的连续过程图。未经实测的视频播放能力不写成已完成。
- 原理课用连续图示讲清动作。用户否定了以长段文字和四个磁场箭头为主的初稿。
- 用户指定演示形式参考：爱上半导体《电机怎么控制转多少度！原理最容易理解的电机！步进电机的工作原理！》，BV1cN4y197TG，分享链接 https://b23.tv/lAjyuEE。
- 原理图和动画自行绘制，实物图片优先选用清晰的原始照片并记录来源。标明简化模型与实物结构的区别，电流、磁极和转向必须一致。
- 底层引脚资料见 `hardware/motor-driver/netlist.enet` 和同目录 README。该文件是 AT32M416 电机驱动板网表。

## 后续课程的讲解参考

用户指定《什么是步进电机》《步进电机的结构和工作原理》《电机的力矩》《步进电机的选型》为讲解参考。先让学生看到实物或一个熟悉的动作，指出图中哪一处发生变化，再用短句说清原因。遇到力矩、转速等能量化的概念，给一个带单位的算例。后续课可以接着用同一个例子，例如先用卷筒算力矩，再把卷筒的转速和力矩带到选型曲线上。

合编稿以这四份原稿为底稿，按原来的顺序分成四课。直接保留讲得清楚的段落、算例、配图和参数表。补齐缺失的图和公式，修正会误导读者的技术表述，按统一模板排版。前一版的图可以用来补充原稿缺失的图解。

详略按四份原稿的讲解密度取舍。一个图段集中讲一处变化，观察、原因和在电机上的用法自然接起来。涉及电能生磁时，先让读者看到磁铁怎样带动转子，再看通电前后磁针的变化，最后回到固定线圈。读图已经能得到的信息合并成一句，关键因果允许多用一幅图或一页。

H 桥结构图和换向图采用网上清晰、简洁的现成原图。图注写明来源，按资料标注作者和许可。正文按原图的开关编号或位置讲清通路。

第五课从绕组电流换向讲到四只开关组成 H 桥，最后落到两相各接一组 H 桥。FOC 和 PWM 留到后续课程。

## 每节交付前的自审

用户要求作者主动补齐必要基础并完成自审，不能依赖用户逐项提醒。

- 基础课件按用户要求做三轮完整通读。每轮从第一页读到最后一页，记录本轮发现并完成修正，再通读下一稿。交付前以最终文件核对改动处和全篇分页。
- 从学生尚未认识电机的状态读起，检查每个问题是否在前文自然产生、后文是否直接回答。只补齐当前解释必需的前置认识，不把后续课程提前塞入本节。
- 新名词在首次使用时解释。电流、磁场、磁力、转矩，以及电流方向和机械转向，应按实际含义使用。
- 每幅图核对实物与简化模型的差别、电流沿导线的方向、磁场方向、N/S 极性、手势和观察视角。方向图必须固定“从哪一端看”。
- 将显示出来的图片与原图对照，保留正文会用到的部件、箭头、尺寸、字母和边缘标注。取用截图时沿完整图块的边界裁剪，并核对图注与说明在同一页。
- 以学生身份从头读到尾，检查能否仅凭图文回答基本问题，不依赖作者在课堂上临时补充遗漏。
- 对反向条件做对照。电流反向后磁极是否交换，换观察端后顺逆时针表述是否正确，循环首尾能否形成连续运动。
- 图上的每个状态与正文、动画逐项对应。局部的两个状态不能代替完整循环。
- 完成内容核对后，渲染并检查全部页面。不要为凑页数压缩原模板字体或漏掉关键知识；删除重复文字、调整图的空白后再检查分页。
- 将实际发现的问题、修正内容和核验依据保存在自审记录中，不用主观评分代替证据。
- 固件教学以可追溯的初始源码为依据，目前最早仓库快照为 `214fadc`。后续加入的在线调参、自动电角标定等功能应注明来源，不能当成初始代码已有功能。
