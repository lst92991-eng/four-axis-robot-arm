# 初版验收证据索引

[验收结论与后续事项](../../../初版验收与跨设备交接_2026-11-19.md)。

| 目录 | 内容 |
| --- | --- |
| [match](match/) | 实拍棋局状态、CAN 日志、视觉与引擎检查及取放参数变动 |
| [empty-step](empty-step/) | B2 到 F2 的空跑报告、逐帧遥测和棋盘核对 |
| [j1](j1/) | 制动、STOP、40 V 限幅、20 轮扫参、高低行程及装配检查后的复测 |
| [firmware](firmware/) | 最后确认的 J1 应用 `2e5004d0` 的单节点 OTA 与原始构建清单 |
| [run-source](run-source/) | 保留原相对层级的现场源码和选定配置，可在另一台设备直接阅读 |

同一测试目录内的 `report.json` 是逐段结果，`trace.json` 是原始采样。较长行程和装配检查后那组的样本字段顺序见现场快照中 `run_long_z.py` 的 `record` 函数。其余调参记录中的 `columns` 和 `phase_columns` 定义样本顺序。故障记录和恢复记录与成功测试同时保留。

其中约 30 cm 高位的接续记录保留了触发编码器奇偶校验前后的日志。装配检查后十次往返的位置基于那一组的相对零点。读取一组结束位置时应同时参照相应的 `restore-readback.json`。

现场快照内含本机工作路径、适配器标识和局域网地址。跨设备整理时可直接阅读源码。若需复现实机入口，按原相对层级放入本机工作区并分别核对依赖和设备配置。相机在测试期间换过 DHCP 地址，原配置中的地址是现场留档。视频、生成目录、实时状态与持续增长的本机日志留在原机，Git 归档保留经选取的报告和采样。
