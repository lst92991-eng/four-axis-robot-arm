# J1 短程电角标定接入

用户批准：先沿用六轴验证方法完成 J1 电角标定，再把当前位置记为机械 0°，供手动上位机测试。没有把 `CONFIG_ENCODER_ZERO` 任意改成 0，J1 静态默认值仍为 -1；仅在存在有效标定记录时允许正常闭环。

## 代码与范围

- 来源：桌面 `六轴机械臂项目交接/firmware/StepFOC/src/motor_calibration.c` 及对应头文件。导入指纹见 `j1-calibration-import.json`。
- 本次只构建、更新 J1。适配器在固件内限定 `CONFIG_NODE==1`，只开放基本模式，不开放整圈线性化扫描。
- 过程：无出力静态检查约 0.5 秒 → 固定电角缓升电流对齐 → 一个电周期方向检测 → 返回 → 质量检查 → 缓撤电流 → 结果有效后保存。
- 初次请求 **300 mA**；按 ADC counts 换算实际参考约 298 mA。后续根据方向/返回质量失败逐档试验 600、900 mA，未超过当前项目 1 A 配置及标定相电流保护；具体结果如下。
- 算法原有速度、相电流、传感器、母线、时间、位移和回差检查保留。基本模式原生位移门限为起点 ±450 编码器 counts，约 ±9.89° 电机角度；上游安装流程要求预留约 ±12°。这是电机角度，不能当成升降毫米数。
- 正常完成先缓撤电流，故障/中止由独立功率关断处理。主循环、ADC/编码器采样和 CAN 失联保护继续工作。

## 与四轴固件的适配

电流环保持现有三环计算。标定时仅切换到给定电角的 d 轴电流，q 轴给定为 0；普通 MOVE 在标定期间拒绝。编码器方向和电角转换从通过校验的记录读取，机械位置的正负约定仍由 `CONFIG_DIRECTION` 决定。

启动会读取此前保留的两个电角标定槽：`0x0801F000`、`0x0801F400`。校验 magic/version/极对数/零点/方向/回差/映射和 CRC 后选择较新记录。保存只擦写另一个 1 KiB 槽，不擦其他槽及 `0x0801F800` 后的配置区。保存只允许功率关闭、标定已完成时执行；返回后重读校验。

新增 CAN v3 命令 **9**：`values[0]` 为操作（0查询、1开始、2中止、3保存）；`values[1]` 为请求电流 mA。正常 PING 维持 500 ms 通信看门狗；STOP/OFF 会中止正在进行的标定。标定期间 ZERO/CLEAR/MOVE 被拒绝。

STATUS 保持 64 字节/v3，原有字段不变，使用原来空闲的字段：

| values 索引 | 内容 |
| --- | --- |
| 3 | 标定状态低8位、错误次8位、bit16 RAM记录有效、bit17 Flash记录存在 |
| 5 | 编码器原始累计 counts |
| 6 / 7 | 有效电角 raw_zero / direction，无记录时 -1 / 0 |
| 8 | 本次标定参考电流 mA |
| 11 / 12 | 进度千分比 / 母线 mV |
| 13 | 扩展标记 `0x43414C31` |

## 主机操作

`manual_control/calibrate_j1.py` 默认只观察。指定已核对的构建 ID，`--run` 执行基本标定、保存、机械设零；不发送 MOVE，结束保持功率关闭。`--zero-only` 只在已有保存标定时将当前位置记为机械 0°，不重新做电角标定。它与网页共享一个 USB-CAN，运行前需要暂停网页后端。

固件工件与指纹：`output/j1-calibration-20261106/J1-manifest.json`。升级只用 `J1.ota`，不覆盖引导程序。主机更新工具增加可配置的等待复位时长，除等待时长外不改变原 CAN 更新流程。
