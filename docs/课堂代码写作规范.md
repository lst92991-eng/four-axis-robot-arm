# 课堂代码写作规范

适用于机械臂的 `app/`、`vision/`、`chess/`、`motion/`。课上一段代码讲清一件事，读者能从第一条调用顺着看到实物或画面结果。

逐函数审核时，以用户明确认可的五步视觉主循环为参照。提交旧、新两段实际调用与必要的函数体，指出学生少维护了什么、哪一步的输入输出更清楚，并附同一批输入的结果。涉及 SDK 或测试工具时，交代原有工作去了哪里。相机循环曾经只改注释而遗漏用户要求的重试行为，这种改动应在源码对照时就被发现。[视觉版本对照与审核实例](视觉教学写法的演变与审核依据.md)

## 逐行手写的十二条规范

1. **按实物工作的顺序排主流程。** 初始化在循环前，一轮从读输入走到输出，退出后收尾。读一手棋，应能顺着找到确认棋局、选棋、规划取放、执行、核对落点和记谱。
2. **先交代本轮要讲的数据。** 在第一次使用前就近声明并简注输入、中间结果与输出。一帧可以先摆出原图、模型输入、三路输出、棋子列表和预览，再连续写五步调用。
3. **一个循环回答一个业务问题。** 例如用 `while (running)` 处理一帧。为回放限定帧数的参数和计数归测试入口。等待停稳、等待新帧各用实际结束条件。
4. **普通函数明示输入和输出。** 多项结果或带寿命的设备输出用具名参数交付，单一结果允许直接返回。成功、退出、恢复原盘、确认目标盘要能从调用处区分。
5. **名字和类型交代数据含义。** 棋格用行列，图像用像素，基座用毫米，关节角写单位。重要中间量使老师可以就着当前函数解释给谁使用、何时有效。
6. **把真正难的计算展开。** 框的中心、宽高和原图偏移可以各占一行；五次轨迹中的距离、时间和速度同理。设备调用和失败判定在读者需要分别理解时分开写。
7. **子函数完成一项独立工作。** 读取候选框、筛重、还原坐标各有独立产物。只有转交参数的重载、没有消费者的包装应删除，并检查调用方是否仍隐藏同一份复杂度。
8. **一件事只有一个判定来源。** 棋谱在落点确认后提交一次。已有循环条件、传入数据或调用位置能够确定的信息，直接使用；为同一事实设置两面标志会增加学生的记忆负担。
9. **在能决定下一步的地方检查。** 临时读帧失败由采集处处理；缓冲绑定失败由设备边界收尾。运动失联须停车、落子未确认须等实盘。正常一手棋里只留下真正改变下一步的分支。
10. **先确定固定条件，再保留变化量。** 固定机型、模型规格、首次示教值各交代一次。TOML 在安装入口读取，格点和动作在内存里传递；设备改为同步取帧后，相应的后台缓存、锁与通知应一起撤掉。
11. **中文注释说明物理含义、单位和顺序。** 用短功能分区快速定位；解释为什么先抬高再横移、为什么按 SDK 行距读数据。函数名和赋值已经说清的内容直接读代码。
12. **打开函数体验收，拿同一输入对照。** 展示改前和改后的实际代码，说出删了哪项状态或判断、学生少理解什么。用同一帧核对识别，用同一手棋核对目标、吸放顺序、停稳、错误恢复和记谱；实机、模拟和代码审核分别记录。

## 最小充分设计

从手头这套硬件和要完成的一次操作写起。以固定芯片的初始化为例，按手册顺序使能时钟、写入功能位、启动外设。手册要求等就绪时，就在启动处等它指定的就绪位。芯片型号已经由板型和构建确定，通电后无需再读 ID 来选择同一条路径。逐项回读、权限事务和镜像校验各有适用场景，在实际需要它们的入口处理。

- **默认写直接路径。** 先让学生用已知前提完成一次操作。遇到真实的新输入或故障后，再在产生问题的那一处补处理。
- **在数据第一次进入时建立前提。** 示教值由 TOML 读取，三点标定成功后直接使用坐标表。棋盘上的新画面仍须核对，因为棋子、遮挡和帧内容会改变。
- **只传下一步实际要用的数据。** 开局核对接收这张盘面，本手合法走法只在本手保存。若一个状态只是程序当前调用位置的复述，就用当前调用表达。已有多个转发方也不能证明这个状态有用。
- **保留有现场后果的判断。** 横移前抬到搬运高度，驱动失联时停车，落子核对后再记谱。每项判断应能指出它防的具体问题、检测的数据和触发后的动作。
- **用实际入口验收删减。** 看同一批输入得到的盘面、动作和失败出口。测试覆盖实际需要的行为。测试夹具造出的中间状态无需变成课堂程序的长期契约。

## 对照到机械臂

几何课固定取红左、红右、黑左三个角。格点按行列步长生成，从检测中心反算行列时用 OpenCV 的双精度 `Matx22d::solve`。配置用 toml++ 读取，象棋合法着法和搜索用 Pikafish；应用层负责实盘归格、核对和机械取放。三轴轨迹维持已验证的共同进度曲线和实测停稳条件。

每次改动完，从实际入口顺读一遍普通走子、吃子和退出。使用相同样本核对格点、检测和动作。有效行数作为对照记录，代码能直接手写复现才算完成。
