## 文件

- `camera_bridge.SLDASM`：9个打印组件的独立SolidWorks 2026固定装配；零件在`parts/`。
- `camera_bridge.step`：通用CAD装配；`print/`内5个STL按下表打印。
- `layout_check.png`、`layout_check.step`：包含机械臂、参考棋盘、相机和主板的安装场景。棋盘位置仍是布局参考，实际可达工作区另行验收。

- `source/`：本轮生成与验证脚本；`*-sketches.json`记录草图约束及特征消费关系。普通打印不需要运行Python。

## 打印与使用边界

- 镂空侧梁平躺打印，让长边/三角框处于打印XY平面。两端1.9mm搭接面、梁耳局部悬空须检查切片。
- 卡座侧放，卡唇、梁根夹片和螺母窝可能需要局部支撑；不是整套免支撑设计。先在切片预览中确认卡槽没有残留支撑妨碍试装。
- 可从PETG、0.2mm层高、4道外壁开始试制；薄梁大多由外壁决定强度，实际用料以切片为准。长期蠕变、温升、卡座松动和相机摆动需要实物观察。
- 机械臂振动会传到相机。取图应安排在停车并稳定后；靠角标重投影/棋盘边缘位置记录稳定时间，不宣称软件滤波已解决机械抖动。
- 运动件、工具和线束的完整扫掠尚未验收；CAD几何检查不能替代实机运动与承载验证。

实际STL实体体积约166.09cm³，相比V1的CAD实体体积约减少89.88%。这不是切片耗材克数；卡座支撑、裙边及打印设置仍会改变实际用料。

## 修改模型

通常直接编辑`parts/`中的SolidWorks草图和特征，再核对装配位置即可。装配固定在参考位置，修改梁长/卡座高度后不能假定其他组件会自动跟随。

脚本是本机SolidWorks 2026 COM生成记录，依赖已安装的`solidworks-automation-mcp`技能、pywin32、NumPy和Pillow；其他电脑需设置`SCARA_SW_SKILL`、模板路径及输入模型位置。生成顺序为`build_bridge.py clamps beam camera pcb`→导入用户STEP后运行`pcb_reference.py`→`assemble_bridge.py`→`assemble_bridge.py scene`→`verify_bridge.py`。重建会覆盖相应生成文件，先保留自己的改版。普通打印和原生CAD编辑不需要这套脚本环境。
