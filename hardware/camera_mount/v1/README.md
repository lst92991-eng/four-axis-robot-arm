# 全打印 MIS5001 B 相机支架 V1

2026-10-09。结构件全部3D打印，采用普通螺栓/螺母/垫片连接；没有铝型材长杆。已在本机SolidWorks 2026创建可编辑草图/特征零件及定位装配，导出STEP和毫米单位STL。**这是可切片的设计原型，尚未打印、试装或验证长期承载。**

## 1. 先看哪些文件

- `camera_mount.SLDASM`：只含打印支架，配套零件在`parts/`，装配位置固定。
- `camera_mount.step`：支架的通用CAD文件。
- `layout_check.step`：支架、原机械臂及参考棋盘的静态场景；不拿整场景去打印。
- `print/`：仅这里的STL是待打印结构件，单位mm。
- `source/`：SolidWorks API构建脚本及厂家尺寸图；可编辑的原生零件仍是主要CAD源。
- `assembly-layout.json`：从实际新装配读取的零件变换，不是手写示意位置。

解压时保留目录结构，先打开`camera_mount.SLDASM`。原生文件由SolidWorks 2026生成；较旧CAD可使用STEP。整机场景采用STEP交付，避免要求另一台电脑具备原机械臂的本地文件路径。

原机械臂不是本支架的支撑点，立柱放在棋盘后侧。原机械资料文件保留原字节，不把本轮支架设计并入原装配源文件。

## 2. 名义布局与高度

按当前项目坐标：机械臂肩轴为XY原点，棋盘网格中心为(0,250)mm，含角标的棋盘外框为`x=-260..260、y=10..490`mm。

| 项目 | 默认设计值 |
|---|---:|
| 相机立柱中心 | (0,630)mm，位于棋盘后侧 |
| 后臂＋前臂 | 150＋200mm |
| 相机孔阵中心相对臂端前伸 | 30mm |
| 立柱到相机孔阵中心总水平伸出 | 380mm |
| 底脚安装板厚度 | 10mm |
| 四段立柱堆叠净高 | 4×150=600mm |
| 柱顶至梁中心高度 | 100mm |
| 相机安装板底面低于梁中心 | 40mm |
| 相机背面支柱 | 6mm |
| 相机PCB厚、前方轴向长度 | 1mm、16.6mm（厂家B版尺寸图） |
| 镜头前端距底脚安装面 | **646.4mm** |

高度链：`10+600+100-40-6-1-16.6=646.4mm`。若棋盘表面比底脚安装面高`b`毫米，镜头离棋盘的距离是`646.4-b`，不能忽略厚棋盘/不同桌面的高度差。光心与镜头前端也不是同一点，正式标定使用实际相机模型。

官方图给出PCB25×24mm、四孔中心距21×13.5mm、背面连接器突出2mm，但没有标孔径，也没完整给出光轴到孔阵的偏置。支架按孔阵中心布置，安装后用实拍核对光轴与棋盘中心，不把示意相机外形当精密原厂CAD。

`03_height_spacer_50`每加一件，名义镜头高度增加50mm：约646、696、746、796、846mm。也可以减少150柱段再搭配50增高件，但低于约600mm的档位不能直接用于完整机械臂行程；原CAD推算最高运动件约538mm，固定顶部约594mm，工具/线束还未完整建模。**本设计为拆装分档调高，不是连续滑动调节。**

## 4. 紧固件与安装

| 位置 | 初选紧固件 | 数量/限制 |
|---|---|---|
| 底脚、柱段及柱顶法兰连接 | M4×25螺栓、垫片、锁紧螺母 | 默认20套；每增加50mm段再增加4套 |
| 双面悬臂拼接板 | M4×45、垫片、锁紧螺母 | 4套，贯穿6＋20＋6mm夹层 |
| 相机座夹臂 | M4×45、垫片、锁紧螺母 | 2套；槽宽20.6mm配20mm梁，单侧名义间隙0.3mm |
| 主板托盘 | M4×60、垫片、锁紧螺母 | 2套，贯穿6mm托盘和40mm梁；确认伸出端不碰线缆 |
| 相机PCB | M2螺栓、绝缘垫/垫片及螺母，约20mm长为初选 | 4套；**先核对PCB真实孔径**，打印座孔为2.8mm并不证明模块孔径 |
| 底脚锚固桌板/硬底板 | M5贯穿螺栓＋大垫片＋螺母 | 4套；长度按实际桌板厚度选，不能只靠小脚自由摆放 |
| 主板 | 绝缘垫/间隔支撑、绑带 | 按实际板形布置，避免压元件并保留散热空间 |

柱段定位凸台39.6mm，承口40.4mm，单侧名义间隙0.4mm。它用于定位，紧固靠四个M4螺栓；不要只凭插接摩擦承载。每个螺栓都应有足够螺纹啮合，不能拧到塑料明显压瘪。表中螺钉长度是按CAD厚度选择的起点，不替代垫片、螺母和实物试装检查。

装配顺序：锚固底脚→四段立柱→带撑后臂→前臂和双侧拼接板→相机座→主板托盘→相机及线缆。先用低档、不装电子件试合定位台和螺孔，再装到计划高度。

## 5. 打印建议和需要支撑的位置

- 以毫米导入，保持100%尺寸；切片前放平贴底。最长件200mm，按约220×220×180mm成型空间准备，并计入裙边；更小打印机应先重新拆分，不要整件缩放。
- 先打印一节短增高件检查39.6/40.4定位配合，再决定是否调整补偿。打印误差、材料收缩与孔径偏差必须以自己的机器为准。
- 可从4～5道外壁、约30%～40%填充、0.2mm层高开始试制，材料与强度以实物验证。相机旁的主板需要散热，打印结构应避开持续高温。
- 柱段可竖放，但上法兰比方管每侧外伸15mm，需要支撑。它不是免支撑设计；后臂安装环和相机座夹臂也要检查悬空区域。
- 前臂与拼接板尽量让主要弯曲平面位于打印XY平面；后臂可侧放配支撑，关注安装环、三角撑根部和层间连接。底脚底面朝下。
- 默认所有零件的CAD实体体积约1.64L；实际耗材由壁厚、填充、支撑和切片决定，不能直接用体积乘填充率。全打印长支架的用料与打印时间应先在切片软件中确认。

厂家/打印设计参考：[Prusa建模与打印配合说明](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135)。

## 6. 16cm排线与视野

用户实物MIPI排线为**160mm**。主板托盘靠近相机端，前缘与相机参考轴相隔约45mm；CSI连接器应朝相机，并先按真实路径试绕，保留弯曲及应力释放余量。不能把160mm全部当直线可用长度。大网线和电源线沿梁、柱固定，拉力不传到相机或MIPI接口。

相机镜头向下，PCB在小安装板下方，支柱给背面连接器留6mm空间；镜头前端比小板底面低23.6mm。主板托盘和前臂都在镜头上方。后臂下撑及立柱虽有低于镜头的部分，但位于棋盘后方，经几何投影检查不侵入参考棋盘视野。

用户截图指向MIS5001广角无畸变B版：[官方光学参数](https://wiki.luckfox.com/MIS5001-5MP-Camera/)为2.88mm、F2.4，DFOV95.5°、HFOV87.5°、VFOV56.5°。**95.5°是对角视场，不是垂直视场。**这些标称H/V角与当前1280×960采集比例不能直接互相推出，实际裁剪/视场仍用完整四码和棋盘实拍验证。

板端现IQ中的FNumber=1.6与B版厂家F2.4不同，保留这一差异供后续相机阶段核对。本轮不改ISP配置，也不把IQ值当作镜头实测值。

## 7. 已检查与尚待验证

已完成：SolidWorks新零件与定位装配、原生/STEP/STL导出；8类STL均为封闭实体，毫米尺寸和正体积检查通过；相机孔阵及柱段配合尺寸已核对。SolidWorks对11个打印组件的干涉检查为0处（不把接触面算作干涉，不含紧固件/电子件/线缆）。按实际装配变换检查520×480mm棋盘及800×600mm留边区域，支架侵入参考视锥为0处。原机械资料目录的61个文件逐一与用户原ZIP比对，字节未变。实际结果见JSON验证记录。

尚未完成：打印尺寸试配、装配承载/长期下垂、桌面锚固、实际排线路径、全关节/工具/线束扫掠、实拍视场与标定。原机械臂在移动时仍可能挡住棋子；支架不挡棋盘不等于机械臂永远不遮挡，拍照仍安排在机械臂停车后。

先在不运动条件下装好、锚固、检查镜头视野及支架摆动，再进入用户指定的分阶段硬件调试。支架成果不自动代表电机或视觉阶段通过。

## 8. 修改与重新生成

通常直接编辑`parts/`内SolidWorks草图/特征，再更新装配即可，不必运行脚本。装配使用固定位置而不是运动配合；改尺寸后需同时复核零件位置、孔位和相机高度。

需要从脚本重建时：打开SolidWorks 2026，准备64位Python及`pywin32`、`Pillow`，依次运行`source/build_mount.py`与`source/assemble_mount.py`。默认模板为本机SolidWorks 2026的`gb_part.prtdot`与`gb_assembly.asmdot`；安装目录不同需修改脚本中的模板路径。脚本将覆盖本包内对应生成文件，先保存自己的改版。打印和普通CAD编辑不依赖这套Python环境。
