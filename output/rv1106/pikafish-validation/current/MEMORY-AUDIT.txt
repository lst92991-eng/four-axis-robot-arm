Current network is ZSTD, unlike the older 2023 ZIP release:
Compressed 49982985 bytes; decompressed 64137632 bytes (61.166 MiB).
ZSTD window 2 MiB; decoder estimate 2586424 bytes.
src/misc.cpp read_compressed_nnue materializes the complete decompressed
network in a stringstream, then network.cpp fills the final in-line network.
The stringstream is moved/elided, not copied again. Its buffer is transient.
read_compressed_nnue has no raw-input branch: simply replacing this current
model with an uncompressed file does not work.
FeatureTransformer reading is in-place; permutation temporary is <=128 bytes.
The full FeatureTransformer copy in write_parameters is export-only.

A streaming decompression or raw-input patch would lower loading peak, but
not the measured 161836 KiB steady state. Disabling cross-process sharing
would similarly not remove a permanent duplicate; the 61 MiB network is
still required. Such changes alone do not fit MemAvailable 149708 KiB.
No further source changes were made for this memory audit. Prefer the older
validated version plus raw weights for this board unless requirements allow
broader storage-layout or search-history changes to the current version.
